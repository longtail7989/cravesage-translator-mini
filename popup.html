실행 중인 확장 업데이트 필요

팝업과 백그라운드의 버전 또는 지원 기능이 다릅니다. 이전 코드로 가져오기·초기화를 실행하지 않도록 작업을 잠갔습니다.

다시 로드하면 팝업이 닫히며 진행 중인 파일 작업은 중단됩니다. 저장된 캐시와 설정은 유지됩니다. 이후 팝업을 다시 열고, 진행 상황을 확인한 뒤 게임 화면도 새로고침해 주세요.

게임 적용 설정

프로필 닉네임과 이야기 속 주인공 이름은 다를 수 있습니다. 원문 이름 직접 입력은 자동 감지 실패 시 대체·테스트용입니다. 공유 캐시는 이름 대신 {USER}를 사용합니다. 각 이름은 64자 이하이며 < > { }와 줄바꿈은 사용할 수 없습니다.

변경 후 저장해야 적용됩니다.

대상 언어와 원문이 일치하는 캐시를 우선 적용하며, 이름 공유 캐시는 감지·입력한 이름으로 표시합니다. 없는 번역은 원문 그대로 표시하며 AI 번역·네트워크 요청은 하지 않습니다.

캐시 파일

추가 파일은 기본적으로 병합합니다. 큰 파일은 NDJSON / JSONL, 기존 JSON v1·v2·v3는 32 MiB 이하를 지원합니다.

큰 작업 전 새 탭으로 여세요. 완료될 때까지 팝업·탭을 닫지 마세요.

백업에는 원문·번역문과 수동 수정이 포함됩니다. 순차 저장 미지원 환경의 다운로드는 32 MiB까지만 가능합니다.

모든 언어의 번역과 수동 수정만 초기화합니다. 설정과 디스크의 캐시·백업 파일은 유지됩니다.
