# 크레이브사가 번역기 Mini

기존 [cravesaga-translator](https://github.com/longtail7989/cravesaga-translator)의 캐시 파일을 읽어 게임에 적용하는 **독립적인 캐시 전용 Chrome 확장**입니다. 프로젝트 이름은 `cravesage-translator-mini`, 현재 릴리스는 **v0.1.4**입니다.

AI 번역·API 키·ChatGPT helper·리모콘·배포 수집 기능은 없습니다. 확장은 번역 서버에 연결하지 않으며 **캐시에 없는 문구는 원문으로 유지**합니다. 게임 자체의 서버 통신까지 차단하는 기능은 아닙니다. 게임 이미지 OCR도 하지 않습니다.

[Mini v0.1.4 다운로드 · 확장 ZIP과 SHA256SUMS](https://github.com/longtail7989/cravesage-translator-mini/releases/tag/v0.1.4)

## 설치

1. Chrome 116 이상에서 원본 전체 번역기 및 다른 한글패치를 끕니다. **같은 게임에 동시에 사용하지 마세요.**
2. 배포 ZIP을 고정 폴더에 풀거나 이 프로젝트 폴더를 고정된 위치에 둡니다.
3. `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램 로드**에서 `manifest.json`이 있는 폴더를 선택합니다.
4. 툴바의 Mini 아이콘을 열어 캐시 파일을 가져옵니다. 기본값은 `한국어`, 캐시 적용 켜짐입니다.
5. 이미 실행 중인 게임은 진행 상황을 확인한 뒤 직접 새로고침합니다. 지원 주소는 `https://gg-client-r.crave-saga.net/client/*/index_dmm.html`입니다.

원본 확장과 Mini는 확장 ID·IndexedDB 저장소가 다릅니다. **기존 캐시가 자동으로 공유되지는 않습니다.** 원본에서 파일로 내보낸 후 Mini에서 가져오세요. 원본 확장이나 개인 데이터를 삭제할 필요는 없습니다. 설치 폴더를 이동하거나 확장을 제거하기 전에는 먼저 백업하세요.

폴더 안의 파일을 업데이트한 뒤에는 **Mini 확장 새로고침 → 팝업 다시 열기 → 게임 화면 새로고침** 순서로 적용합니다. 파일만 바꾸면 새 팝업과 이전 백그라운드가 섞일 수 있습니다. 팝업은 실행 버전과 초기화·비차단 가져오기 지원 여부를 확인하고, 맞지 않으면 작업을 잠근 뒤 **확장 다시 로드** 버튼을 표시합니다. 다시 로드는 저장된 캐시·설정을 지우지 않지만 진행 중인 파일 전송은 중단합니다.

0.1.4는 전체판 0.3.10까지의 변경 중 캐시 전용 Mini에 해당하는 이름·대사·백로그 처리를 반영합니다. 업데이트 후 팝업의 **v0.1.4**를 확인하세요. 기존 캐시를 삭제하거나 다시 가져올 필요는 없습니다. 실시간 번역·리모콘·배포 기록·자동 클릭은 추가하지 않습니다.

## 캐시 로드와 추가 병합

팝업의 **캐시 파일**에서 파일을 선택하고 **파일 가져오기**를 누릅니다.

- **추가 병합 / 로컬 번역 유지**: 기본값. 기존 원문·언어가 있으면 로컬 항목을 유지하고, 파일에만 있는 항목을 추가합니다. 수동 수정도 유지합니다.
- **추가 병합 / 파일 번역으로 덮어쓰기**: 별도 확인 후 중복 항목을 파일 값으로 교체합니다. 기존 수동 수정도 바뀔 수 있습니다. 파일에 없는 로컬 항목은 유지합니다.
- **전체 교체**: 별도 확인 후 기존 캐시 전체를 파일 내용으로 교체합니다. 파일에 없는 항목과 수동 수정은 사라집니다. 먼저 백업하세요.

기존 JSON v1/v2/v3는 **32 MiB 이하**, 큰 파일은 **source-v3 NDJSON/JSONL v2/v3**를 사용합니다. NDJSON은 한 줄 UTF-8 1 MiB 이하이며 헤더·항목·종료 개수가 필요합니다. 전체 파일을 메모리에 읽지 않고 작은 배치로 형식·고유키를 검증하고 임시 저장한 뒤 한 트랜잭션으로 반영합니다. 잘린 파일·잘못된 고유키·필수 필드 누락·반영 실패는 기존 캐시를 먼저 지우지 않습니다.

기존 번역기 팝업이 기록하는 `exportedAtISO`와 Mini의 `exportedAt` 날짜 필드를 모두 지원합니다. JSON의 선택적 `identity: source-v3` 메타데이터도 읽습니다. 기존 파일을 직접 편집하거나 다시 내보낼 필요가 없습니다.

**번역 내용 차이는 파일 파손과 구별합니다.** 원문과 번역문의 숫자·태그·변수·줄바꿈이 다르더라도, 형식과 고유키가 맞는 항목은 파일 내용 그대로 저장·적용·내보냅니다. 완료 안내에 **실제로 반영한 항목의 내용 차이 경고 개수**를 표시합니다. 경고 항목을 몰래 제외하거나 고치지 않으며, 로컬 유지 정책으로 건너뛴 항목은 경고 개수에 넣지 않습니다. 직접 수정할 때의 보호 검증은 별도로 유지합니다.

큰 작업은 팝업의 **새 탭**으로 열어 진행하세요. 완료될 때까지 팝업·탭을 닫지 마세요. 취소는 협력적이며 이미 시작된 최종 반영은 완료될 수 있습니다. 중단된 임시 작업은 만료 정리 또는 다음 서비스 워커 시작 시 회수합니다.

## 캐시 전체 초기화

팝업 **캐시 파일 → 캐시 전체 초기화**에서 별도 확인 후 모든 언어의 저장 번역과 수동 수정본을 삭제합니다. 검색 결과와 편집 중인 번역 초안, 게임의 메모리 번역도 초기화하여 원문으로 돌아갑니다.

**언어·글꼴·게임 원문 이름·표시 이름·적용 On/Off 설정과 아직 저장하지 않은 설정 입력값은 유지**합니다. 디스크의 가져오기 파일·백업 파일도 지우지 않습니다. 초기화는 되돌릴 수 없으므로 필요한 캐시는 먼저 NDJSON으로 백업하세요.

초기화 전에 시작된 가져오기·내보내기 작업도 무효화합니다. 이전 창의 늦은 가져오기 완료가 캐시를 다시 채우지 못하게 하며, 초기화 뒤 새로 시작한 파일 가져오기는 정상적으로 사용할 수 있습니다. 파일 **전체 교체**는 선택한 파일을 검증한 뒤 기존 캐시를 바꾸는 작업이고, **캐시 전체 초기화**는 파일 없이 빈 상태로 만드는 작업입니다. 어느 쪽도 설정 전체 초기화는 아닙니다.

## 번역 검색·수정·삭제

1. **번역 찾기 · 수정**에서 원문 또는 번역문을 검색합니다. 빈 검색어는 목록 조회이고, **원문 정확히 일치**는 대상 언어도 입력해야 합니다.
2. 조회는 범위별 최대 512개/2 MiB를 검사하고 결과 최대 20개를 표시합니다. **다음 범위 검색**으로 계속 찾습니다. 전체 캐시를 한 번에 메모리에 올리지 않습니다.
3. 항목을 선택해 번역문을 편집하고 **번역 저장**을 누릅니다. 원문·언어·고유키는 변경할 수 없습니다.
4. 숫자·태그·일반 변수·줄바꿈의 내용과 순서는 유지해야 합니다. 이름 자리표시자 `{USER}`만 번역 어순에 따라 위치를 옮길 수 있으며 개수는 같아야 합니다. 다른 탭에서 먼저 수정한 경우 충돌을 알리고 작성 중인 초안을 보존합니다. **최신 항목 다시 불러오기**는 별도 확인 후 초안을 버립니다.
5. **번역 삭제**는 확인 후 선택한 항목 하나만 삭제합니다. 별도 `{USER}` 항목이나 다른 원문의 번역까지 묶어서 삭제하지는 않습니다.

가져오기·수정·삭제 후 게임의 메모리 캐시를 무효화합니다. 활성 게임 화면은 다시 조회하며, 숨겨진 게임 탭은 돌아왔을 때 갱신합니다. 게임 왼쪽 위 리모콘이나 현재 화면 편집 UI는 만들지 않습니다.

## 대사 점진 표시와 백로그 재사용

확인된 `AdvText`·`AdvTextExtension`의 `getPlaneText()` 전체 원문으로 캐시를 조회합니다. 일본어가 한두 글자씩 나오는 중에도 전체 원문의 번역을 찾고, 한국어는 원래 게임의 표시 진행률에 맞춰 서서히 보여 줍니다. 이름을 먼저 대치한 뒤 한글 자모·이모지 결합 문자·태그·변수가 깨지지 않는 경계로 표시하며 게임의 원문·시간 설정·진행 상태는 바꾸지 않습니다.

시작 전 진행률 0에서는 빈 문자열, 완료 시에는 전체 번역을 표시합니다. 캐시 응답이 원문 표시 완료 후 도착하면 전체 번역을 바로 보여 주며 처음부터 다시 재생하지는 않습니다. 캐시 미등록·적용 Off·연결 해제 시에는 마지막 실제 일본어 표시분을 유지·복원합니다. 진행 정보를 검증할 수 없는 일반 라벨과 백로그는 전체 번역을 표시합니다.

**팝업 편집·캐시·내보내기는 항상 전체 저장 항목을 사용합니다.** 화면에 잠깐 표시된 접두어를 새 원문·번역문으로 저장하지 않습니다. 새 타이프라이터 옵션이나 캐시 변환은 필요 없습니다.

대사와 백로그의 **전체 바깥 `<size=N>` 태그와 보호 영역 밖 줄바꿈만 다른 경우**에는 같은 번역을 재사용합니다. 먼저 정확한 원문과 `{USER}` 원문의 정확 일치 캐시를 모두 찾고, 없을 때에만 대사·백로그로 확인된 문맥에서 형식 차이 후보를 조회합니다. 정확 일치 수동 번역은 계속 우선합니다. 다른 UI의 공백·문자·태그 속성·변수 내부를 추측하여 맞추지 않습니다.

내용 차이 경고가 있는 항목은 정확 조회·편집·백업에서 그대로 보존하지만 다른 형식의 대사로 재사용하지는 않습니다. 재사용은 보조 인덱스로 최대 32개·1 MiB를 확인하며 후보 안에서는 수동 수정·최신 시각·고유키 순으로 결정합니다. 기존 캐시의 보조 필드는 작은 배치로 준비하고 중단 시 이어서 처리합니다. 원본 고유키·내용·저장 개수는 바꾸지 않으며 임의의 별칭 항목을 새로 만들지 않습니다.

삭제한 정확한 원문은 다른 형식 후보만으로 되살리지 않도록 삭제 표시를 남깁니다. 별도의 `{USER}` 캐시가 남아 있으면 다음 이름 후보로 사용할 수 있습니다. 해당 원문을 명시적으로 다시 가져오거나 전체 초기화하면 삭제 표시도 해제됩니다.

## 백업과 설정

**NDJSON 백업**은 저장된 번역 전체를 파일에 순차 기록하며 수동 수정 표시·저장 시각을 보존합니다. 순차 저장이 없는 환경은 32 MiB 이하에서만 다운로드 대체 저장을 사용합니다. 파일 선택 취소·권한 거절·디스크 쓰기 실패 시 완료로 표시하지 않습니다. 백업은 전역 스냅샷이 아니므로 일관된 파일이 필요하면 다른 관리 탭에서 동시에 수정하거나 가져오지 마세요.

대상 언어·글꼴·**캐시 번역 적용**은 **설정 저장**을 눌러 반영합니다. 글꼴을 비우면 게임 원래 글꼴을 유지합니다. 적용을 끄면 원문·원래 스타일로 돌아가며 캐시는 삭제하지 않습니다.

캐시 식별자는 SHA-256(`JSON.stringify(['crave-cache-v3', 대상 언어, 정확한 원문])`)입니다. 문맥·모델·화면별로 분리하지 않고 공백·줄바꿈·Unicode를 정규화하지 않습니다. 대상 언어도 파일과 정확히 맞아야 합니다. 브라우저 저장 할당량과 디스크 여유 공간 제한은 남습니다.

## 사용자 이름을 공유하는 캐시

원문과 번역문에 같은 개수의 `{USER}`를 넣은 캐시는 사용자마다 다른 이름을 복원할 수 있습니다. 원문에 정확히 일치하는 기존 캐시를 먼저 조회하고, 없을 때만 현재 이름을 `{USER}`로 바꾼 공통 문장을 조회합니다. 실제 게임의 이름과 별개인 일반 문구를 무조건 바꾸지는 않습니다.

- **게임 원문 이름**을 비우면 게임의 플레이어 데이터에서 주인공 이름과 계정 닉네임을 읽습니다. 로그인 전에는 준비를 기다리고, 이름 변경 후에는 이전 요청과 표시 캐시를 무효화합니다. 게임 버전 변경 등으로 감지가 안 되면 화면의 원문 이름을 직접 입력할 수 있습니다.
- **번역에 표시할 이름**을 비우면 해당 문장에 대응하는 현재 게임 이름을 씁니다. 원하는 한국어 표기가 있으면 직접 입력하고 **설정 저장**을 누르세요. 이 설정은 공유 캐시 파일 자체를 개인 이름으로 덮어쓰지 않습니다.
- **백로그 화자·본문**도 같은 표시 이름을 적용합니다. 게임이 로그에 실제 닉네임을 넣었거나 기존 정확 일치·수동 캐시 번역에 그 이름이 남아 있어도, 현재 원문에 확인된 이름만 화면에서 대치합니다. 태그 속성·다른 이름과 기존 파일 내용은 그대로 유지합니다. 화면에는 개인 이름이 나오고, 공유 `{USER}` 항목의 편집·백업에는 자리표시자가 남습니다.
- 이름을 알 수 없는 경우 `{USER}`를 화면에 그대로 출력하지 않고 원문을 유지합니다. 감지에는 추가 서버 요청·게임 설정 변경·OCR을 사용하지 않습니다.
- 이미 작성자의 이름이 문자열로 저장된 기존 파일은 자동으로 공통화하지 않습니다. 정확한 원문 이름과 번역 대응 표기를 확인한 변환본이 필요합니다. 다른 사람·캐릭터의 동명 이름은 임의로 일괄 치환하면 안 됩니다.
- 원래 이름이 포함된 개별 캐시가 남으면 정확 일치 항목이 우선합니다. 공유 캐시를 테스트하거나 배포할 때는 먼저 백업하고 확인된 변환본으로 **전체 교체**하세요. 추가 병합은 기존 개별 항목을 삭제하지 않습니다.

코드 업데이트 후에는 확장을 다시 로드하고, 진행 상황을 확인한 뒤 게임도 직접 새로고침해야 새 MAIN/ISOLATED 스크립트가 연결됩니다. 개인정보가 있는 원본·변환 캐시 파일은 소스 저장소에 포함하지 않습니다.

## 개발·검증·빌드

Node.js 22.13 이상. 외부 패키지 설치가 필요 없습니다.

```sh
node scripts/test.mjs
node scripts/build-extension.mjs --out dist --tag v0.1.4
```

빌드는 명시적인 허용 목록의 확장 파일만 넣은 재현 가능한 ZIP과 `SHA256SUMS`를 생성합니다. 테스트·문서·개인 캐시·계정 데이터는 ZIP에 포함하지 않습니다. 버전을 변경할 때는 `manifest.json`과 `core.mjs`의 `VERSION`을 함께 변경하세요. 빌드 명령 자체는 GitHub 업로드·웹 스토어 게시·자동 업데이트를 하지 않습니다.

실제 브라우저 IndexedDB 회귀 검증:

```sh
node tests/serve.mjs
```

별도의 테스트 브라우저 프로필로 `http://127.0.0.1:8766/tests/native.html`을 열고 **검증 실행**을 누릅니다. `/popup.html`은 Chrome 메시징만 테스트 호스트로 연결하며 저장은 실제 IndexedDB를 사용합니다. 이 호스트는 배포 파일에 들어가지 않습니다. `tests/mock-game.html`은 실제 게임 없이 Cocos 접근자·콘텐츠 스크립트를 검증하기 위한 합성 화면입니다.

### 구조

- `main.js`: MAIN world의 Cocos 텍스트 추적·캐시 표시·원문 복원.
- `name-policy.js`: 실제 이름과 `{USER}` 템플릿 사이의 리터럴 치환·현재 이름 복원.
- `dialogue-text.js`: 전체판과 같은 제한적인 대사·백로그 형식 동등성과 표시 복원.
- `story-text.js`: 검증된 전체 원문·진행률 관찰과 한국어 그래핌 단위 점진 표시. 자동진행 기능은 포함하지 않음.
- `content.js`: ISOLATED world의 읽기 전용 브리지·짧은 배치 조회·제한된 메모리 캐시.
- `background.mjs`: 팝업/게임 요청 권한 경계·설정·캐시 변경 알림.
- `cache*.mjs`, `core.mjs`: 파일 형식·IndexedDB·원자적 병합·수정 충돌 검증.
- `popup.*`, `file-transfer.mjs`: 팝업 관리 UI·파일 순차 입출력.

## 개인정보·권리

권한은 `storage`와 지정 게임 호스트 접근만 사용합니다. API 제공자용 추가 호스트·`nativeMessaging`·`offscreen` 권한은 없습니다. 게임 페이지에는 전체 캐시나 팝업 관리 명령을 공개하지 않습니다.

캐시 파일에는 게임 원문·번역문·사용자 이름 등이 포함될 수 있으므로 공유 전에 확인하세요. 게임 및 캐릭터 이미지 권리는 원저작권자에게 있으며 비공식 도구입니다. 원본 프로젝트의 캐시 형식·검증 및 Cocos 연동 구조를 바탕으로 만들었습니다.
